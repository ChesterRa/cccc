## 范围与原生边界

### 日志实现修订（用户确认，取代下文阶段历史中的管道方案）

- 安装子进程的 stdout/stderr 沿用原生 `Stdio::from(file)` 直接写入文件，不等待换行，不新增单行大小阈值，不因日志超过 8 MiB 中止安装。
- 原始输出按任务及命令分文件保存，Unix 文件权限 0600、任务输出目录 0700；它们是原始日志，不宣称已脱敏，不通过 API 返回文件内容的任意路径。
- 阶段、退出结果等小型任务记录保留现有 JSONL 与游标。查看子进程输出时复用原生诊断日志尾部读取（64 KiB 分块、最多 8 MiB、最近 200 行），再统一脱敏；一页最多展开一个输出文件，避免多文件输出叠加。文件中完整输出与页面尾部视图明确区分。
- 只有版本、路径等需要程序解析的查询结果才在命令结束后读取；保留既有 1 MiB 结构化结果校验，不把它称为日志写入上限。
- 超时、停止及进程归属继续使用 OwnedProcessTree。文件直接写入不再存在管道 EOF 收尾任务；输出写入错误由子进程、文件打开/同步及退出结果呈现，不宣称父进程能够观察子进程自行忽略的每一次 write 错误。

- 覆盖 CCCC 当前全部已知 Agent CLI 的安装、升级及 CLI 自动升级计划；沿用 Runtime 标识，不另建智能体身份或模型目录。
- **CLI 卸载**：首期占位已由本页顶部的真实卸载修订取代；后台仅接受可确认归属的受管安装，保留原生日志、权限和任务机制。
- Web 入口为设置的全局范围，沿用现有设置导航、组件、表单草稿、API 返回结构及中英日 locale。包管理器使用 mise，不要求用户另开运维系统或手写命令。

- Runtime 不等于 Agent CLI。`web_model` 标记不适用；`custom` 保留原行为，不能根据任意命令猜测安装包。DeepSeek 复用已有受控组件安装，不破坏 CCCC 固定依赖合同。
- 本功能不改变 Actor、会议、Group、会话或 IM Bridge 语义。安装成功、登录状态和真实模型可用分别陈述。

## 安装与升级合同

- 软件安装与选中版本保存在本 CCCC Home 下的专属目录，不覆盖系统/npm 全局安装，不改用户 Shell 配置，不删除登录或历史。
- 先解析具体目标版本，隔离安装，再验证可执行文件；成功后原子记录选中版本。失败保持旧选中版本，不将失败命令标为成功。
- 已是目标版本时先验证现有安装；可执行文件、依赖或版本验证异常则在本次任务的新目录重新安装，不要求用户卸载后重试。重新安装仍须验证成功才切换，失败保留原选择与文件；后台停止或取消不得触发修复安装。
- API 仅接受已知 Runtime 与受限操作，不接受任意软件包、脚本、命令或文件路径。
- 新启动 Actor 使用已选中版本；已有进程继续原版本，不被静默终止。页面明确“新版本对后续启动生效”，不冒称现有 Actor 已升级。原生会话保持原有恢复语义。
- 默认命令的版本选择同样适用于内建 Voice Analyst 的下一次进程启动；显式自定义路径不被替换。选择发生在启动边界，不改写保存的运行配置或会话身份指纹，也不因 CLI 更新强制替换已运行的 Analyst。内建助手的默认参数继续由其既有启动适配器提供，不套用普通 Actor 的参数。
- 安装/升级是后台任务，响应任务 ID；状态、阶段日志与输出尾部视图可查。完整原始输出保存在受保护文件中，不宣称其已脱敏。浏览器关闭不终止执行。命令超时需停止其拥有的子进程，不停止无关 Actor。
- 日志文件创建失败则不启动命令；文件同步及结构化结果读取失败不能标为成功。子进程自身处理文件 write 错误，沿用原生重定向边界；父进程不保证发现子进程自行忽略的写入错误。
- 进程退出或终止后，进程回收最多等待 5 秒；若操作系统拒绝结束进程树则明确失败，不无期限等待。进程归属和终止继续由 OwnedProcessTree 负责。不存在管道读取或 EOF 收尾任务。
- 无 mise、平台不支持、缺依赖、网络失败及安装验证失败须有可操作错误；不可通过运行任意远端脚本掩盖不支持。

## CLI 自动升级计划

- 多条实例级规则，作用于已纳管且已安装的 CLI；未安装不自动安装，外部安装不自动接管。
- 沿用 CCCC 现有 `interval`、`cron`、`at` 调度概念与时间计算。周期界面为每天/每周单日/每月；多星期使用多条规则。固定时刻默认 03:00，初始不启用自动规则。
- 保存时固定时区，显示下次执行时间；不因浏览器所在地变化改写既有计划。间隔单位分钟，至少一分钟；一次性规则执行后不重复。
- 规则持久化带版本，过期编辑拒绝覆盖。到期领取和任务入队原子完成，进程重启不会重复领取同一时刻。
- 错过的周期至多合并为一次检查，不重放所有历史时刻；同一 CLI 安装/升级不能重叠。后台重启后的不确定任务显示中断，不自动冒险重复执行。
- 调度只复用通用计算和交互，不伪装成向 Actor 发提醒，也不修改工作组的自动化策略。
- API 保存的复杂 cron 无法用日/周/月预设等价表示时，界面展示原表达式并保留，不伪装成每天或静默改写。仍可修改启用状态和时区；需要重设周期时由用户显式切换调度类型。

CLI 自动更新计划的五段 cron 按现有 Web 合同解释星期：0/7 为周日、1 为周一。转换仅在 `cli_management.rs` 私有计算入口中完成：复制 trigger，将星期转换为库编号并补秒，再调用未修改的原生调度函数。保存校验、首次计算及到期后计算下一次时间均使用该入口；持久化与 API 中的原始表达式、时区和已保存下次时间不变，无需迁移现有 CLI 计划。

不修改 `automation_schedule.rs` 或工作组自动化调用路径，不给公共函数新增转换开关。原有工作组五段表达式仍只补秒并按库编号解释，六/七段表达式保持原行为；原生 Web 与工作组后端的星期编号差异不在本功能内修复。CLI 计划接口仍只接受五段 cron，内部转换出的六段表达式不作为新的外部接口。

验收要求：CLI 的星期 0–7、列表/范围/步长/名称、日/月末和非法值；保存/重载不改表达式，到期后续排程一致且不重复入队；同一五段表达式通过工作组入口仍保持旧日期。术语检查：本次沿用 CLI 自动更新计划、工作组、trigger，无新增定义；其他已报告术语及规格整理项不属于本次 cron 修订。

2026-09-10 隔离修订验证：`cargo test -p cccc-pair-core --offline` 共 232 项通过（205 项单元、27 项集成，包含 CLI 管理 13 项），上述新增边界均通过；原有工作组自动化集成回归通过。`automation_schedule.rs` 与源码基线 `0e9e2832` 完全一致，原生格式和差异检查通过。未修改 Web、部署或推送；此前部署记录不代表测试机已应用此补丁。

## 后台接口

| HTTP 入口 | Daemon 操作 | 行为 |
|---|---|---|
| `GET /api/v1/cli-management` | `cli_management_get` | 返回现有 Runtime 清单、安装来源决策、纳管安装、计划与任务状态 |
| `GET /api/v1/cli-management/jobs/{job_id}/log?offset=0` | `cli_management_log` | 管理员读取阶段记录及子进程输出的脱敏尾部视图；返回 `entries`、`next_offset` 与 `has_more`，输出文件引用由后台解析、不回传 |
| `POST /api/v1/cli-management/jobs` | `cli_management_submit` | 接收 `runtime`、`operation`、`request_id`；后台任务持久化入队，重复请求返回原任务 |
| `PUT /api/v1/cli-management/schedules` | `cli_management_schedules_update` | 接收 `revision`、`rules`；过期编辑返回冲突，不覆盖保存结果 |
| `POST /api/v1/cli-management/uninstall` | `cli_management_uninstall` | HTTP 501，错误码 `cli_uninstall_not_implemented`；不提交任务或改变安装 |

列表也是全局管理员接口。所有入口统一检查 Web 身份、CSRF 和权限；Daemon 保持本机受信控制面的边界，要求 `by=user`，拒绝 Actor 控制身份。该字段不是 OS 级安全隔离，不能宣称同一系统用户下任意进程无法模拟本机 IPC。

提交通用操作时传入 `operation=uninstall` 同样返回上述未实现错误。`web_model`、`custom` 和未知 Runtime 不入队；不接受用户提供的包名、命令或安装路径。任务入队不是安装成功，只有安装及验证完成后才更新 `installations`。

## 权限与错误处理

- CLI 管理不提供外部错误通知；使用任务状态、页面反馈、任务日志及守护进程日志。
- 列表、操作、计划、日志均使用现有 CCCC 全局管理权限；不允许普通组权限从 HTTP 绕过。现有本地可信访问语义保留。
- 后台入口同样拒绝 Actor 冒充普通控制操作；不通过现有模型工具自动开放软件管理。
- 阶段与错误记录脱敏保存，包含阶段、Runtime、任务 ID、退出状态与原因。原始 stdout/stderr 按上述受保护文件合同保存，页面读取时脱敏，原始文件不自动对外发布。不自动发送到聊天频道或外部 Webhook。
- 终端颜色码先清理再进行凭据匹配，不能让格式化字符拆开字段名或凭据后绕过脱敏。已知环境凭据存在前缀包含关系时优先替换长值，避免短值替换后残留长凭据尾部。
- 卸载任何时候返回稳定的未实现错误；无相关子进程、文件删除和计划动作。
