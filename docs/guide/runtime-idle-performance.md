# 提示条调度与输入区布局优化

## 行为

- Runtime Dock 提示原先在存在未过期条目时每 250ms 轮询。现在按缓存中的最近过期时间设置一次 timeout；数据变化时重算，不重复延长同一条目的 6 秒展示期。
- 页面隐藏或提示被 suppressed 时取消展示计时器，恢复后按原 receivedAt 补算；不停止后台消息接收。卸载清理监听和 timeout。
- 输入框 minHeight === maxHeight 时直接设置固定高度，不读取 scrollHeight，也不因每次输入重复运行尺寸 effect。动态高度模式继续在 paint 前同步调整，避免额外帧写入带来的跳动。

## 验证

22 项相关测试覆盖精确过期、无轮询、隐藏时零计时器、后台新消息恢复、过期消息不复活、suppressed 和卸载清理，以及固定高度零布局读取和动态伸缩。

真实 Ego 页面中对独立测试 textarea 做 200 次固定高度调整（不改用户草稿）：旧算法约 203 次布局，新算法 0 次；函数循环耗时约 6.6ms → 0.3ms。此为针对性微基准，不代表整页 CPU 同比例下降。手机宽度下动态高度仍从 128px 收缩到 52px，页面无水平溢出。

## 范围

本轮保留虚拟列表参数、既有测量缓存和 observer；没有额外添加 rAF 包装、FastDOM、React Scan 或监控上报。后续只有性能轨迹证明对应热点存在时才改，避免以配置调整替代测量。
