# Runtime Dock 动画性能

工作中的 Agent 保留渐变旋转圈。动画施加于独立 HTML span 层，SVG 只绘制静态圆弧；避免对 SVG 子 circle 每帧旋转引起布局失效。只有工作状态保留动画，后台页面暂停并释放 will-change 提示，系统减少动态效果时禁用动画。

2026-10-26 在 Ego 0.6.0.20 / CCCC 开发页同一工作组进行各 8 秒对照：原 SVG 子元素旋转 1062 次布局、1.19 秒主线程任务；暂停单个旋转圈 112 次、0.34 秒；恢复原动画 1018 次、0.86 秒。HTML 外层合成实验 90 次、0.41 秒。结果为该环境短时测量，不代表所有浏览器或整机卡顿均已解决。

回归：RuntimeDockRing.test.tsx 覆盖可见→隐藏→可见与工作→空闲状态；RuntimeDock.test.tsx 保留尺寸、状态及操作合同。真实浏览器验收动画目标为 SPAN，减少动态效果下 animation-name 为 none，并以 Performance.getMetrics 对照布局与任务耗时。

实现后线上本机开发页复测（8 秒）：105 次布局、299 次样式计算、0.52 秒主线程任务；动画目标确认为 SPAN，减少动态效果为 none。相对于上述原始测量，布局约减少 90%，主线程任务耗时约减少 56%。后台暂停的状态转换由组件测试覆盖；Ego 自动化切换诊断标签时仍报告页面 visible，不能把该操作当作真实后台暂停验收。
