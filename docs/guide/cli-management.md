# CLI 管理

本文说明开发分支的 CLI 管理功能。受管优先、真实卸载与易读计划摘要属于最新修订，不代表现有部署或上游版本已包含；完整验证状态与逐项支持范围见 [功能规格](../specs/cli-management.md)。

## 入口与准备

在 Web 的“设置”中选择“全局” → “CLI 管理”。页面面向整个 CCCC 实例，而不是当前工作组（Group）；沿用既有全局管理权限。

CCCC 进程所在环境须已安装 mise，且该进程的 `PATH` 能找到它。如果 CCCC 在容器中运行，安装操作也发生在该容器中，不会安装到访问网页的电脑。管理员负责持久化 CCCC Home，否则删除容器后其中的软件和管理记录也可能丢失。

软件安装与供应商登录分开：本页不创建账户、不购买订阅、不修改模型或推理强度，也不证明真实模型调用已经可用。

## 安装与更新

1. 在运行时（Runtime）列表中找到需要的智能体 CLI（Agent CLI），点击“安装”。已有外部安装时显示“安装受管版本”，创建独立副本，不覆盖外部软件；也可以不安装，继续使用原生探测到的外部版本。
2. 在“CLI 操作记录”查看进度、手动或计划触发来源、创建/开始/结束时间；点击“查看日志”读取该次操作的阶段、退出结果及标准输出/错误输出的脱敏尾部视图。输出视图沿用原生最近 200 行、最多读取 8 MiB 的方式，并非完整文件；这些是查看限制，不是日志单行或写入上限。提交成功只表示操作已接收；关闭页面不会停止后台执行。安装、更新、卸载共用队列，在同一实例内逐项执行。
3. 安装及验证成功后，列表显示受管版本。后续点击“更新”检查并安装目标版本；没有新版本且现有安装通过验证时不重复安装。
4. 若同版本的文件、依赖或版本验证异常，更新会尝试在新目录重新安装。只有新安装验证成功才切换，失败不覆盖旧文件或旧选择。

新版本对后续启动的智能体（Actor）生效。正在运行的 Actor 继续使用原版本，不会因为更新而被停止。显式指定其他可执行路径的 Actor 保留自己的命令，不被自动改写。CLI 更新不等于重启 Actor，也不等于清空原生会话。

本页仅显示 17 个可管理的 Agent CLI。Web Model（`web_model`）没有本地 CLI，Custom（`custom`）无法从任意用户命令安全推导安装来源，因此不在本页显示；智能体配置中的相应运行时选项保留。DeepSeek 使用 CCCC 已验证的固定组件组合，不随意切换到上游 latest。

## 默认使用来源与卸载

默认启动优先使用已经验证并保存的受管安装；没有受管记录时，沿用 CCCC 原有的 PATH 探测。页面显示当前默认来源与路径，没有“外部来源选择”或“切换来源”配置。Actor 显式指定的程序路径仍优先，不被全局默认改写。外部软件不能通过此页更新、自动更新或卸载。

点击“卸载受管版本”并确认后，后台只删除该 CLI 安装任务所属的全部受管软件目录（包括旧版本和随版本安装的依赖），不删除外部安装、供应商登录、原生会话、工作组、Actor、计划或任务日志。相关 Actor 或内建助手仍运行时拒绝卸载，请先停止后重试；不会自动停止使用者。

卸载成功才移除受管记录。下次默认启动恢复原生探测；若外部也未安装，则显示不可用。已保存的自动更新计划保留，但跳过已卸载的 CLI。Actor 手工写入的旧受管绝对路径不会自动修改，卸载后需要自行调整。

卸载失败可能已删除部分目录，受管记录仍保留并报告错误，不承诺文件级回滚，也不会静默使用外部版本。查看任务日志后重新提交卸载，或更新修复安装。受管记录存在而文件、依赖损坏时，页面同样提示不可用。

使用保护覆盖 CCCC 启动的 Actor 与内建助手，不是整台设备的进程管理。自行从其他终端运行受管路径的进程应先由管理员停止；不扫描或终止任意系统进程。

## 自动更新计划

点击“添加计划”，沿用 CCCC 现有调度控件：

| 类型 | 设置方式 |
|---|---|
| 间隔 | 每多少分钟检查，至少一分钟 |
| 周期 | 每天、每周某一天或每月某一天，固定时刻默认 03:00 |
| 一次性 | 指定将来时刻，或多少分钟后执行 |

新计划默认未启用，确认设置后自行启用并保存。每周单条规则选择一天，例如星期一和星期四更新，需要两条规则。计划只更新已受管且已安装的 CLI，不自动安装尚未安装的软件，也不接管外部安装。

周期按保存的计划时区执行；计划列表和编辑器显示例如“每天 03:00（Asia/Shanghai）”，而非要求用户理解 `0 3 * * *`。这只是摘要呈现，不修改 cron 存储或调度。“下次执行”按浏览器本地时间显示。每月选择 31 日时，没有 31 日的月份不执行。一次性计划执行后不重复；停机错过的周期最多合并检查一次，不重放所有历史时刻。

通过 API 保存的复杂 cron 若不能由日/周/月控件等价表示，页面保留并显示原表达式，不会悄悄改成每天。可以修改启用状态和时区；需要重新设置周期时，显式切换调度类型。

多个页面同时修改计划时，过期保存会被拒绝并保留当前草稿。取消编辑、刷新后重新修改，不要把冲突提示当作保存成功。

## 错误与日志

通过任务状态、页面错误提示、任务日志及 CCCC 守护进程日志排查。不提供专用错误报告配置，不向外部 Webhook 发送通知。旧版本留下的通知配置文件不再读取，也不会自动删除。

安装过程 stdout/stderr 直接写入 CCCC Home 下 `cli-management/logs/<任务编号>/`，每条命令独立保存。Unix 原始文件权限为 0600、目录为 0700。原始文件可能包含敏感信息，不是脱敏文件，不应直接分享；页面读取时才脱敏，不自动外发原始日志。小型阶段与退出记录保留为脱敏 JSONL，旧版 JSONL 日志仍可查看。

| 情况 | 处理 |
|---|---|
| 未找到 mise | 管理员在 CCCC 所在环境提供 mise，并使 CCCC 进程能找到它；不要在浏览器所在电脑安装代替 |
| 安装或更新失败 | 查看该任务日志，处理下载、依赖或验证错误后重试；旧选中版本不会被失败结果替换 |
| 请求结果尚未确认 | 先刷新查看已有任务；本页面对同一操作重试会复用请求编号 |
| 已中断 | 后台重启后无法确认先前任务完成情况，不自动重放；查看记录后按需重新提交 |
| CLI 管理后台发生错误 | 查看守护进程日志，检查存储空间、文件权限和管理状态路径；后台完整迭代恢复后可刷新页面。不把保留的旧任务快照当作后台仍健康执行的证据 |
| 计划配置冲突 | 草稿没有保存；取消编辑、刷新后重新修改 |
| 安装成功但 Actor 无法回答 | 分别检查实际启动路径、供应商登录和原生协议；安装测试不能替代这些检查 |

本页不提供手工版本回切或定期清理旧安装、旧日志；仅在显式卸载时删除该 CLI 的全部受管安装。不要在会议进行中手动删除受管目录来代替卸载。
