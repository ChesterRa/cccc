# Standards

CCCC publishes its collaboration and daemon contracts as versioned standards. Start here when you need to build a compatible client, bridge, SDK integration, or daemon-facing tool.

## Current Standards

- [CCCC Collaboration Standard (CCCS) v1](/standards/CCCS_V1) defines the event envelope, routing semantics, attention/ack behavior, and cross-group provenance model.
- [CCCC Daemon IPC v1](/standards/CCCC_DAEMON_IPC_V1) defines daemon transport, request/response shapes, streaming events, and operational commands.
- [CCCC Context Ops v1](/standards/CCCC_CONTEXT_OPS_V1) defines context operation semantics used by daemon clients and integrations.
